## Executive summary

Teachers grade far more than homework / quiz / test. Industry SIS/LMS products (PowerSchool, Canvas, Google Classroom, Skyward, FACTS) converge on **named categories + weighted groups + flexible assignment columns** — not one locked global enum.

**Recommendation: hybrid model**

1. Seedable **work-kind** vocabulary (for AI hints, filters, chips)  
2. Class **syllabus categories** with weights (AVG-P1 owns the math)  
3. Map kind → default category; teacher can refile  
4. Per-column **score schemes** (numeric / pass-fail / letter / rubric / complete-incomplete / narrative)  
5. Spring Baptist v1: richer labels + schemes + capture hints; defer full weighted engine / SBG / behavior-as-GPA  
6. Never auto-publish AI scores; Approve gate stays
