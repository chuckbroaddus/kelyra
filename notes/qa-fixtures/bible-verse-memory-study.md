# Memory Verse Study

**Verse to memorize:**  
"For God so loved the world, that he gave his one and only Son, that whoever believes in him should not perish, but have eternal life." — John 3:16 (WEB)

**Practice activities:**
1. Write the verse from memory 3 times.
2. Circle the word "loved". What does this tell us about God?
3. Short reflection (2-3 sentences): Why do you think this verse is important?

**Due:** Friday

---

## Teacher Notes / Suggested Answers

- Reflection sample: "It shows God loves everyone and wants us to have life forever if we believe."
- No grading on belief; focus on recall and basic comprehension.
- Source note: Verse text is public domain. This fixture uses only the single verse, not any study guide or commentary.

**Total points possible:** 10 (5 recall, 5 reflection)
