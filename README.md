# Kelyra

A hybrid mobile + web AI tool for K-12 teachers. Kelyra emphasizes voice and camera capture, incremental student metadata, AI gap analysis, individualized practice exercises, and a practical grade book.

## Folder structure

```
kelyra/
├── docs/        Product vision, design notes, and project documentation
├── research/    Discovery, competitive notes, and source material
├── src/         Application source
├── notes/       Working notes and scratch thinking
├── README.md
└── .gitignore
```
